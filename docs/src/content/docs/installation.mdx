# Installation

Logseq Copilot supports all major browsers. Choose your preferred browser below to get started.

## Supported Browsers

### Chrome <Badge text="Recommended" variant="tip" />

Get the extension from the Chrome Web Store:

[**Download for Chrome →**](https://chrome.google.com/webstore/detail/logseq-copilot/hihgfcgbmnbomabfdbajlbpnacndeihl)

### Microsoft Edge

Available on the Edge Add-ons store:

[**Download for Edge →**](https://microsoftedge.microsoft.com/addons/detail/logseq-copilot/ebigopegbohijaikegebaaboaomaifoi)

### Firefox

Download from Firefox Add-ons:

[**Download for Firefox →**](https://addons.mozilla.org/en-US/firefox/addon/logseq-copilot/)

## Browser Compatibility

:::tip[Chrome-based Browsers]
Most browsers based on Chromium (like Brave, Opera, Vivaldi) support Chrome extensions. If you're not using Firefox or Safari, try the [Chrome version](https://chrome.google.com/webstore/detail/logseq-copilot/hihgfcgbmnbomabfdbajlbpnacndeihl).
:::

:::caution[Safari Not Supported]
**Safari** is currently not supported because registration in the Apple Developer Program is required, which costs US$99 per year.

If you really need Safari support, consider [becoming a sponsor](/sponsor).
:::

## After Installation

Once you've installed the extension, you'll need to:

1. **Set up your Logseq API server** - [Setup Guide →](/setup)
2. **Configure the connection** between the extension and Logseq
3. **Start capturing highlights** and building your knowledge base!

## Troubleshooting

If you encounter any issues during installation:

- Make sure your browser is up to date
- Check if the extension appears in your browser's extension manager
- Restart your browser after installation
- Visit our [GitHub Discussions](https://github.com/EINDEX/logseq-copilot/discussions) for help
