## Built for your graph and your privacy

<Columns>
  <div>
    <h3>File graphs and DB graphs</h3>
    <p>Logseq 0.10 and Logseq 2.x. The extension finds out which one is open.</p>
  </div>
  <div>
    <h3>Your notes stay yours</h3>
    <p>The extension only talks to the Logseq HTTP API server you run. Its panels on web pages sit in a closed shadow root, so scripts of the page cannot read your Logseq search results.</p>
  </div>
  <div>
    <h3>Chrome, Edge and Firefox</h3>
    <p>Firefox 127 or later. Safari is not supported. The interface follows the theme of the page and of your system, in light and dark.</p>
  </div>
</Columns>

## What's new in 2.0

Logseq Copilot 2.0 supports Logseq DB graphs next to file graphs, runs on Firefox, adds recall rules, page highlights with comments and templated clipping, and moves the highlights list into the browser's own sidebar. The extension is rebuilt on the [WXT](https://wxt.dev) framework. [Read what's new in 2.0](/blog/logseq-copilot-2-0/)
