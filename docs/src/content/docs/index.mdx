## What it does

<CardGrid>
  <Card title="Notes next to your search" icon="magnifier">
    On Google, Bing, DuckDuckGo, Kagi and other search engines, the blocks and pages of your graph that match your query show up beside the results. [Search engines →](/features/search-engines/)
  </Card>
  <Card title="Notes for the page you are on" icon="document">
    Open the popup on any page to see the notes that mention its address. The toolbar icon shows how many there are. [How recall works →](/features/recall-rules/)
  </Card>
  <Card title="Recall rules" icon="setting">
    Tune the recall for a website: ignore the URL hash or query, exclude or prefer keywords, search or skip certain pages, cap the number of results. [Recall rules →](/features/recall-rules/)
  </Card>
  <Card title="Clip with templates" icon="list-format">
    Clip a selection, or the page link, into your journal, the current page or a page of your choice, in the shape of a template you write. [Clipping & templates →](/features/clipping-and-templates/)
  </Card>
  <Card title="Highlights in the browser sidebar" icon="bars">
    The highlights of the page you are reading are listed in your browser's own sidebar: the side panel in Chrome and Edge, the sidebar in Firefox. It follows the active tab. [Highlights sidebar →](/features/highlights-sidebar/)
  </Card>
  <Card title="Highlight comments" icon="pencil">
    A clipped selection stays highlighted on the page. Click it to add a note. Highlights and notes are stored in your browser. [Highlight comments →](/features/highlight-comments/)
  </Card>
</CardGrid>

## Built for your graph and your privacy

<CardGrid>
  <Card title="File graphs and DB graphs" icon="open-book">
    Works with Logseq 0.10 (file graphs) and Logseq 2.x (DB graphs). The extension finds out which one is open, so there is nothing to switch.
  </Card>
  <Card title="Chrome, Edge and Firefox" icon="laptop">
    Install it from the Chrome Web Store, Edge Add-ons or Firefox Add-ons. Firefox 127 or later. Safari is not supported.
  </Card>
  <Card title="Your notes stay yours" icon="approve-check-circle">
    The extension only talks to the Logseq HTTP API server you run. The panels it draws on web pages sit in a closed shadow root, so scripts of the page cannot read your Logseq search results.
  </Card>
  <Card title="A Logseq look, light and dark" icon="moon">
    The interface uses the Logseq teal and follows the theme of the page and of your system, in light and dark.
  </Card>
</CardGrid>

## What's new in 2.0

Logseq Copilot 2.0 supports Logseq DB graphs next to file graphs, runs on Firefox, adds recall rules, page highlights with comments and templated clipping, and moves the highlights list into the browser's own sidebar. The extension is rebuilt on the [WXT](https://wxt.dev) framework.
