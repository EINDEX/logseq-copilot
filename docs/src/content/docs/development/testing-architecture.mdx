## 重构内容

### 1. 测试环境设置 <Badge text="✅ 完成" variant="success" />

- 支持 TypeScript 和 React 组件测试

- 设置了 DOM API 模拟
- 配置了测试库

#### 测试依赖更新 (`package.json`)

- 添加了 Jest、React Testing Library 和相关工具
- 配置了测试脚本命令

### 2. 服务接口和依赖注入 <Badge text="✅ 完成" variant="success" />

## 最佳实践

### 编写测试

```typescript
describe('MessagingService', () => {
  let messagingService: IMessagingService;

  beforeEach(() => {
    // 使用模拟实现
    messagingService = new MockMessagingService();
  });

  it('should send messages correctly', async () => {
    const message = { type: 'test', payload: {} };
    await messagingService.sendMessage(message);
    // 验证消息发送
  });
});
```

### 服务注册

```typescript
// 在生产环境中注册真实服务
container.register(SERVICE_KEYS.MESSAGING, MessagingService, true);

// 在测试环境中注册模拟服务
container.register(SERVICE_KEYS.MESSAGING, MockMessagingService, true);
```

### 依赖注入

```typescript
class MyComponent {
  constructor(
    private messagingService = container.get<IMessagingService>(
      SERVICE_KEYS.MESSAGING,
    ),
  ) {}
}
```

## 运行测试

### 测试命令

```bash
# 运行所有测试
pnpm test

# 运行特定测试
pnpm test -- --testNamePattern="MessagingService"

# 生成覆盖率报告
pnpm test -- --coverage

# 监听模式
pnpm test -- --watch
```

### 测试配置

测试环境配置在 `jest.config.js` 中：

```javascript
module.exports = {
  testEnvironment: 'jsdom',
  setupFilesAfterEnv: ['<rootDir>/__setups__/jest-setup.ts'],
  moduleNameMapping: {
    '^@/(.*)$': '<rootDir>/src/$1',
  },
  collectCoverageFrom: ['src/**/*.{ts,tsx}', '!src/**/*.d.ts'],
};
```
